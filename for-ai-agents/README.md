# Rin Chat resources for AI models and agents

Plain Markdown files written for AI models, so an assistant or agent can help you write character cards, build
Adventure Mode games and answer questions about Rin Chat without guessing. Copies of the files on
[rin.chat/llms](https://rin.chat/llms/), refreshed with every release.

Give your AI a link and ask for what you want. If it cannot open links, download the file and attach it, or
paste it into the chat. For example:

> Read https://rin.chat/card-format.md, then write me an AICC character card for a retired starship pilot who
> runs a noodle bar.

The rules for AI agents using these files, and the same list for crawlers, are in [llms.txt](llms.txt).

| File | Use it to |
|---|---|
| [AICC card format](../reference/card-format.md) | Write and edit AICC character cards: every field, how each reaches the model, a valid example card. |
| [Adventure Mode games](adventure-game.md) | Write an Adventure Mode game card: the game master boxes and their JSON keys, the character sheet template, roll, choice and command markup, macros and generators. |
| [Interactive cards](interactive-cards.md) | Write cards that go beyond plain chat: choice buttons and forms, document styles, command tags, macros, generators and regex scripts. |
| [Lorebooks](lorebooks.md) | Write and tune lorebooks: how entries trigger, where they land in the prompt, and how they share space with memory. |
| [Troubleshooting and setup](troubleshooting.md) | Help someone install Rin Chat, connect a provider and fix what goes wrong. |
| [Features](../reference/features.md) | Check what Rin Chat does. If a feature is not here or in the guide, do not claim the app has it. |
| [Card grading rubric](../reference/card-grading.md) | Check a card before publishing: the categories, the hard caps, the token penalty and the user agency rule. |
| [Full guide](../guide/README.md) | Everything else, one topic per file. |
